# Study Room Flutter · 一起自习

基于四季窗景的 Flutter 自习室交互原型。按照原始 UX 的移动端页面结构重做：https://wechat.jiuyang.wang/anli/1011/2/seasons/index.html 。采用深蓝房间列表、全屏窗景房间、四列成员墙、底部播放器、金色渐变按钮，以及蓝色标题栏和米金纸色弹层。Flutter 原生组件负责页面与交互，没有嵌入参考网页。

`assets/scenes/` 中的七张场景图片来自参考站点，用于本次 UX 还原。素材源目录：https://wechat.jiuyang.wang/anli/1011/2/_img/ ，文件为 `it_04.webp`、`it_05.webp`、`it_06.webp`、`bg_10.jpg`、`bg_02.jpg`、`bg_03.jpg`、`bg_06.jpg`。原站标注版权归属「云创游科技（西安）分公司」；这些素材不属于本项目原创，正式发布前需要确认素材使用授权。

## 启动

安装 Flutter 3.35 或更新的 stable 版本后：

```sh
flutter pub get
flutter run -d chrome
```

Android 使用 `flutter run`；iOS 需要 macOS、Xcode 和对应签名配置。

```sh
flutter analyze
flutter test
flutter build web
```

## 已有功能

- 访客虚拟身份、注册和昵称头像完善；会员/非会员展示。
- 公开/私密房间；房主审批常驻申请，保留离线成员和最后在线时间。
- 勋章创建、兑换码、限时/终身有效、模拟续费、整枚撤销和单独解除领取者。
- 房间勋章准入检查；房主失去资格后，按管理员顺序转让，无合资格管理员则解散。
- 管理员增删和优先级排序；固定背景、音乐选项和表情开关。
- 双方同意的好友关系，没有私聊。
- 房间表情发送记录。
- 7/30/90 天头像框模拟支付赠礼，收礼后开始计时，多框切换和到期失效。
- 专注计时、本地 JSON 持久化与演示身份切换。

## 演示方法

默认身份为林同学。在「我的」选择「切换演示身份」，可切换陈同学、周同学、新同学和访客，用于演示双方申请、审批和赠礼。访客先在「我的」注册并完善资料，才可创建房间。

在「我的」发行勋章后复制兑换码，切换其他身份兑换。回到房主，在房间设置中审批常驻、添加管理员并排序。通过单独解除房主勋章，可验证转让与解散。

## 原型边界

数据仅保存在本设备；身份切换不是真实认证。会员为演示属性，没有订阅购买；支付和续费不扣款，没有支付平台接入。音乐仅可选择，未接入播放资源；表情暂以事件记录展示，尚非浮动弹幕。没有后端、跨设备同步、真实多人在线或生产权限安全保障。

当前勋章的有效期属于整枚勋章，所有领取者共享；整枚到期或撤销会使全部领取者失效，因此相关准入房间会解散。单独解除房主勋章时，其他持有人仍有效，可按管理员顺序转让。正式业务如果需要每个人独立有效期，应将领取记录拆分为独立权益。

## 代码

- `lib/main.dart`：原生页面、表单、本地存储接入与分层窗景。

- `assets/scenes/`：参考站点场景素材。
- `test/domain_test.dart`：权限、到期、转让、审批、赠礼与持久化测试。
- `test/widget_test.dart`：375×667、320×568 布局和页面交互测试。通过 `flutter test --dart-define=CAPTURE_UX=true` 可额外将房间截图保存到系统临时目录。
